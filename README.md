# Hello from Wadiup · Ruby (Rack)

The smallest Ruby (Rack) web app that Wadiup builds and runs **without a Dockerfile**.

1. New service → Web service → "Or build from Git" → paste this repository.
2. Deploy. Wadiup detects the project type, builds it in-Kingdom and sets `PORT`.

Open the service URL: it answers with the runtime version and the instance name.
